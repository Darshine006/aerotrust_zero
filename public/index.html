Active policy rules

Rules enforced by the current Worker code.

BLOCK · External fork + workflow change

External fork modifying .github/workflows/ is blocked to protect privileged CI/CD behavior.

REVIEW · External fork + sensitive infrastructure

Deployment, Terraform, Kubernetes, infra, or Dockerfile paths require manual review.

ALLOW · No high-risk condition

Changes outside the high-risk rules are allowed by the current policy engine.

ALLOW does not mean code is vulnerability-free.
